# Reimbursement Requests

A modern, intuitive, and secure system for submitting, approving, and processing reimbursement requests.

## Features

- **Project Identity**: Fully branded as "Reimbursement Requests" for professional and consistent internal use.
- **Role-Based Access Control**: Secure login system with a password reset flow ("Forgotten your Password?").
- **Cost Centre Tracking**: Accurate financial tracking with "Cost Centre" assignment for every expense.
- **Workflow Approvals**: Quality Control (QC), Certifying Officer (CO), and Finance workflows mapped perfectly.
- **Multi-language Support**: Interface available in English and Arabic.
